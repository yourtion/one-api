# Changelog

## 0.1.1 (2026-10-24)

> 准备中：本次仅代码和打包验收，尚未发布。

- CSV 导出保留筛选条件，最多导出 10000 行，仅真正超限时提示截断。
- 服务端拦截待改密管理员访问管理功能，相同密码不能解除强制改密。
- 每个 app 使用独立路由实例与 session store；单进程仅允许一个活动服务，关闭后可创建新生命周期。
- 启动失败释放资源，close 幂等并等待启动；库入口不注册进程信号。
- 严格校验端口（整数 0..65535）；运行时要求 Node.js ^22.13.0 || >=24，版本复用共享常量。
